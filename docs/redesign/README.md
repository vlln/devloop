状态：**设计方向已确认，正在落实为仓库协议 2 实现；本目录保留候选与评审历史，不是第二份运行规范，也不表示外部已安装副本自动升级。**

## 定位

devloop 是可安装到项目中的专业软件开发生命周期规范。它使 Agent 与人可以围绕共同目标，持续维护需求、设计、工作、历史和交付，并在多会话、并行协作和需求变化中保持连续性。它不替模型选择每个实现步骤，也不退化为仅有记忆文件的协议。

本草案依据用户已确认的方向及[重设计审计](<audit.md>)编写。审计是问题来源，不是新规范的运行依赖。
