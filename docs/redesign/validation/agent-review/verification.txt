### 独立因果与复现

令可信输入的小计为 `S >= 0`、coupon 为 `C > 0`。现代码返回 `S+C`。当 `S >= C`，较要求 `S-C` 多 `2C`；当 `S < C`，要求为零而实际为正。外层 `max` 不能修正加法。因此普通折扣错、超过小计不归零、空列表时正 coupon 返回正数，都是同一算术方向错误的结果，不另造“地板 bug”。

下表均为本核验者新执行的输入，而非复制 reviewer 的输出：

| amounts | coupon | 契约期望 | checkout 实际 | preview 实际 |
|---|---:|---:|---:|---:|
| `[11, 4]` | 3 | 12 | 18 | 18 |
| `[11, 4]` | 15 | 0 | 30 | 30 |
| `[11, 4]` | 16 | 0 | 31 | 31 |
| `[]` | 4 | 0 | 4 | 4 |
| `[0, 0]` | 4 | 0 | 4 | 4 |
| `[11, 4]` | 0 | 15 | 15 | 15 |

另外 `[10**60, 2]`、coupon=1 要求 `10**60+1`，实际两入口都是 `10**60+3`；不需要浮点误差假设。对 `[11,4]` 令 coupon 依次为 0、1、2，两入口实际依次 15、16、17，折扣增加反而金额增加。

**本核验有限穷举**：列表长度 `0..4`，每个元素 `0..4`，coupon `0..12`。共 **10,153 个输入组合**，每入口 **9,372 次违反公式**，全部为正 coupon；两个入口相互不一致 **0 次**；coupon=0 的 781 组合每入口全部正确。合计公式偏离为 18,744 个入口-case，但仍只有一个根因、两个代码实例，不将测试数量当作发现数量。

两个函数的实际签名均为 `(amounts, coupon=0)`。对 `[]`、`[0]`、`[11,4]`、`[10**60,2]`，分别执行单参数调用、显式位置 coupon=0、关键字调用，每入口各 12 次，共 **24 次均等于小计**；有限穷举还检查输入列表未被修改。因此没有证据支持 parity 缺陷、旧调用签名破坏、零 coupon 回归或副作用缺陷。

## 6. 可重跑的核心证据

在隔离实验工作目录运行以下命令，脚本只在内存加载已提供源码。预期错误计数固定，用于重现当前故障而非绿色产品验收：

```bash
python3 -B - <<'PY'
import importlib.util
from itertools import product

def load(name):
    s = importlib.util.spec_from_file_location(name, 'project/' + name + '.py')
    m = importlib.util.module_from_spec(s)
    s.loader.exec_module(m)
    return m
b, l = load('billing'), load('labels')
n = parity = 0
bad = [0, 0]
zero_bad = [0, 0]
for size in range(5):
    for xs in product(range(5), repeat=size):
        amounts = list(xs)
        for coupon in range(13):
            expected = max(0, sum(amounts) - coupon)
            got = [b.checkout_total(amounts, coupon), b.preview_total(amounts, coupon)]
            n += 1
            parity += got[0] != got[1]
            for i, value in enumerate(got):
                bad[i] += value != expected
                if coupon == 0:
                    zero_bad[i] += value != expected
                assert (value != expected) == (coupon > 0)
assert (n, bad, parity, zero_bad) == (10153, [9372, 9372], 0, [0, 0])
for value in (-7, 0, None, 3.5, '<b>&</b>', ['a', -2], {'negative': -1}):
    assert l.render_label(value) == str(value)
print(n, bad, parity, zero_bad)
PY
```
