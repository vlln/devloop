## 未验证及限制

- 未验证其他 OS/Python 版本矩阵、真实财务 CSV、超大/恶意输入性能；Python 3.9+ 是目标，只有 3.9.6 为本轮实测。
- 本地独立目录为用户授权的实际消费/接收方式，不声称远端财务人员已领取、生产部署或持续运营健康。
- 无独立审查：用户明确允许本 Agent 技术自评和验收，未把角色切换冒充独立视角。
- 金额普通记数且不接受指数、千分位/币种标记；不强制两位小数。这些属于首轮委托内格式选择，已进入现行契约和随包说明。
- 编码/I/O 错误给路径与原因、不保证行号；内容错误给行号。候选前已经明确整理，未将不满足的断言改写为 PASS。
