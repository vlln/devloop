## 验证快照与方法

首轮固定快照位于会话工作区的 `.devloop-validation/2026-10-30/skill`，33 个文件，SHA-256 清单在同目录 snapshot.json。该目录不属于待安装技能，也不改用户已安装副本。快照与运行结果只供本次实验，仓库内保留[摘要、环境、原始执行记录与独立评估](<validation/README.md>)以便复核；本地实验仓库和二进制不并入技能产品。

新/旧项目执行者分别只给技能快照、隔离项目和[固定场景输入](<../../tests/fixtures/README.md>)；不继承主会话设计讨论。后续接手仅给安装后的项目资料，以检验常驻规则及持久化，而非依赖原聊天。

## 已发现及处理

1. 确定结构测试将显式 `$_S` 路由数量误设为至少 10，实际还有相对链接阶段路由。已改为检查至少 5 个显式协议/资源及完整六阶段目标，避免无依据数量门禁。
2. 本机 skit 将 Markdown 链接目标外的尖括号当作路径字符，报告 66 项不存在的目标；独立路径解析均可达。保留合法 Markdown，在隔离副本仅规范化链接后交叉验证通过。未改动 skit 或伪称原命令成功。

3. 汇总评审发现重要独立视角义务只在 skill 引用中，安装后简规缺少明确处理。已在常驻简规补风险适配、作者换角色不替代和无法取得时的关口处置，并增加结构回归检查。最终快照与首轮实验快照仅该模板一处不同；保留两份摘要，不把首轮行为伪称已在最终快照执行。

## 结果边界
