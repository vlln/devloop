# AC 索引

AC 定义什么算满足要求，不记录未经执行的 PASS。每项应有稳定 ID、可复现条件、可执行刺激、可观察结果及判定方式；按风险覆盖必要路径，不强制每项凑正常/边界/异常/失败四格。已有场景 ID 保留，不因新组织方式改号。
