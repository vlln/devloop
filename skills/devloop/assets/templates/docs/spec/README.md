## 模板与维护

[Spec 模板](<0001-template.md>)仅供填写参考，不是现行规范。首份正式文档建立并清理模板时，同步替换本链接和其他引用。

`draft` 表示编写中，`proposed` 表示提交采纳，`active` 表示已采纳且在明确范围生效。多个 Spec 可 active，只要适用对象不冲突。状态不自动产生批准或操作许可。

按信息职责和读者拆分，不为每个二级结构机械分文件。现行正文可受控修订并保持完整连贯；重要变化有来源、基线和影响传播，历史由 Git/决定记录保存。禁止把内部变量和调试过程堆入规格；必要公开字段精确保留。
