## 模板与维护

[Interface 模板](<0001-template.md>)仅供填写参考。建立正式契约并清理模板时同步替换本链接和其他引用。

状态：`draft` / `proposed` / `active`；多个文档可 active，但适用对象不得冲突。重要变化通知实际消费者并处置依赖工作、兼容和验证；共享编辑明确基线与整合责任，不能只靠 Git 无冲突。状态不自动授予部署权限。
