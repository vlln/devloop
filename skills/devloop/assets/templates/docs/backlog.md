# Backlog

工程需求池：已进入工程域、待排期的需求。DESIGN 阶段迭代候选的唯一来源。

## 规则

- 只收**工程域需求**（已定性、可进入 DESIGN 的候选）。未定型、还需调研的想法不入此文件
- 编号 `BL-000x`，递增不复用
- 行序即优先级，高优先级在上
- 状态：`open`（待排期）→ `planned`（已进入迭代，「去向」填关联迭代/执行容器）→ `done`（已发布，「去向」填版本号）/ `dropped`（放弃，「去向」填原因）
- DESIGN 选定条目后改为 `planned`；RELEASE 发布完成后改为 `done`
