# Backlog

持续跟踪的候选、待澄清问题与以后工作。讨论不等于采纳，采纳不等于已排入本轮；一次性问答不必登记。重要插单先对照当前交付承诺与累计净范围，给出处置建议。

## 约定

- `BL-000x` 递增且不复用；沿用已有 ID。只有认领或明确排期后才成为实施承诺。
- 默认状态：`candidate`（想法/待澄清）、`open`（可排期）、`planned`（关联交付/工作）、`done`（该条目的承诺已兑现）、`dropped`（不做，留原因）。已有项目可映射原生状态并说明。
- 优先顺序反映当前建议或已决定排序，标明依据；Agent 可在已有委托内排序，重大取舍由实际有权者决定。
- `done` 说明具体结果/去向，不自动等于生产发布；研究问题可能以研究结论关闭。
- 变更本轮承诺时同步交付、工作与证据影响，不只改本表。暂停/取消的在途工作保留恢复或成果处置入口。
