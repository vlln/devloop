## 维护与恢复

当前协调责任方整合本导航；工作者更新各自记录后通知。重要决定、范围变化、阻塞、集成和交接时更新链接，避免并行覆盖。接管先读相关记录、只读核对活动者与工作区，确认责任和安全操作范围，再做有副作用的验证。不以阶段名或旧摘要代替现实核对。
