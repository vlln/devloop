## 状态与合作

Plan 使用 `pending`、`active`、`blocked`、`paused`、`done`。done 必须有 `outcome: succeeded/failed/cancelled/superseded`；失败不等于目标实现。Report 使用 `draft/complete`，complete 表示记录完整，不表示成功。

认领前明确交付、完成条件、依赖基线、工作区、共享编辑范围及整合责任。计划可受控修订，保留原承诺和变化依据；报告区分已完成、已验证和待验证。暂停有恢复条件，接管先确认活动者与安全范围再做有副作用验证，不能自动丢弃工作树。详见[常驻简规](<../devloop.md>)。
