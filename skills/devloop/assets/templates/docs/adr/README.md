# ADR 索引

记录重要技术取舍、原因与替代关系；不是每个包名或局部实现都需要一份 ADR。技术决定的采纳和外部操作授权分别判断，实际决定来源可在已有范围内复用。

## 状态

| 状态 | 含义 |
|---|---|
| draft | 编写/探索中 |
| proposed | 提出供采纳，未自动生效 |
| accepted | 已采纳，限于明确范围与成立条件 |
| superseded | 被明确的新决定替代，保留历史链接 |
| deprecated | 不再适用于注明范围，说明后果 |

## 模板与维护

[ADR 模板](<0001-template.md>)不是实际决定或批准。建立正式记录并清理模板时同步替换本链接及其他引用。导入已有项目只如实记录已知现状和依据，不编造过去的备选方案、理由或签字。

评审阻塞应有证据、后果和关闭条件；偏好不阻塞，复审关注修订影响。完整协作约定见[常驻简规](<../devloop.md>)。
