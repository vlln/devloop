## 状态与维护

- `planned`：已形成交付安排但尚未开展；`active`：正在推进；`paused`：暂停并有恢复条件；`closed`：已关闭。
- closed 时显式写 `outcome: delivered`、`cancelled` 或 `superseded`，并说明范围结果、未完成项与后续责任。取消原目标不能写成已交付。
- 生命周期责任与工作状态分开。一个交付验收时另一个可设计，不用全局阶段互相覆盖。
- 对话中有效决定与授权可引用复用；用户明确改向则更新范围和相关基线，只澄清新增缺口。
- 交付记录汇总并引用工作报告，不将每个测试日志、内部变量或调试过程搬入正文。
